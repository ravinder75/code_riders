# CONTROLS GUIDE — VECTOR ODYSSEY: WORLDS OF GRAVITY
**Team 6: CODE RIDERS | RESPAWN 2.0**

## 🚀 1. Spaceship Flight Mode (Direct Opening)

| Key | Function | Detail |
| :--- | :--- | :--- |
| **W / Up Arrow** | **Forward Thrusters** | Fires dual plasma engines, accelerating along current ship angle |
| **A / Left Arrow** | **Steer Left** | Rotates spacecraft counter-clockwise |
| **D / Right Arrow** | **Steer Right** | Rotates spacecraft clockwise |
| **S / Down Arrow** | **Retro-Brakes** | Activates reverse thrusters to reduce forward momentum |
| **Space** | **Afterburner Boost** | Consumes boost fuel for maximum velocity flare ($660\text{ px/s}$) |
| **M** | **Sector Radar & Map** | Toggles live sector radar widget and full galaxy system map |
| **Escape / P** | **Pause Expedition** | Opens pause menu to inspect directives or restart |

## 🥋 2. On-Foot Exploration Mode (Cygnus Prime Surface)

| Key | Function | Detail |
| :--- | :--- | :--- |
| **A / D** or **← / →** | **Walk / Run** | Plays 4-frame running animation synced with horizontal velocity |
| **W / Space / ↑** | **Jump** | Plays 4-frame airborne animation (rising, peak apex, fall, landing crouch) |
| **J / Z / F / Left Click** | **Attack (Kamehameha)** | Plays 4-frame energy blast sequence; fires massive beam wave |
| **E** | **Interact** | Inspects Holographic Mathematical Terminals |
| **Escape / P** | **Pause** | Opens surface pause menu |
